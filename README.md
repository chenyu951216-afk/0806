# Gate 爆發前掃幣雷達 v2.1

這是一套針對 **尚未明顯起漲、具現貨提前放量與健康 OI 累積的小型幣** 的掃描、交易計畫與人工持倉追蹤網站。

## v2.1 新增：帳戶 2% 固定風險倉位

在網站上方輸入目前帳戶餘額（USDT）並儲存後，每一個候選訊號都會依自己的固定進場參考價與固定 SL 自動計算：

- 每筆可承受虧損：`帳戶餘額 × 2%`
- 理論名目金額：`可承受虧損 ÷ 止損距離百分比`
- 2% 目標名目：讓價格到固定 SL 時剛好虧損帳戶 2% 的完整名目金額
- 1 倍可執行名目：若目標名目超過帳戶餘額，另外顯示 1 倍最多可下金額、實際風險與最低所需槓桿
- 建議下單數量：`建議名目 ÷ 進場價`
- 到達固定 SL 時的預計虧損 U 與占帳戶比例

例如帳戶 1,000 U、固定 SL 距離 4%，每筆風險額為 20 U，建議名目為 500 U。若 SL 只有 1.5%，理論上需要 1,333.33 U 才會虧 20 U；系統仍會把 1,333.33 U 顯示為 2% 目標名目，同時提醒這需要至少約 1.34 倍；若堅持 1 倍，最多下 1,000 U，實際風險為 15 U（帳戶 1.5%）。

實際成交價改變時，下單視窗會即時重新計算建議名目。使用者仍可手動修改名目金額，但若到 SL 的損失超過帳戶 2%，系統會明確警告。按下「已下單」後，會把當下帳戶餘額、預計 SL 虧損 U 與風險比例一起保存到交易紀錄及 CSV。

可用環境變數：

```env
DEFAULT_ACCOUNT_BALANCE_USDT=1000
RISK_PER_TRADE_PCT=2
```

帳戶餘額在網頁儲存後會寫入 `/data/scanner_v2.db`，重新部署時只要 `/data` 有持久磁碟就不會消失。

## 核心設計

1. **策略資料與即時價格分離**
   - 掃描與趨勢判斷只使用已收 15m／1h／4h K。
   - 即時價格預設每 5 秒更新，用於畫面、掛單區位置與即時損益。
   - 自動止盈止損只用新收完的 1m K，不使用形成中的 K。

2. **交易計畫固定鎖定**
   - 首次建立候選時，固定提前掛單區、突破觸發、回踩區、追價上限、SL、結構破壞點與 TP1／TP2／TP3。
   - 後續重新掃描只更新市場數據，不改固定價位。
   - 計畫只會在到期或結構破壞後，由新基底建立新 Plan ID。

3. **已下單按鈕永遠可按**
   - 系統不會因「暫勿進場」停用按鈕。
   - 不在建議區或高於追價上限時，會顯示手動覆寫警告，但仍可記錄實際成交。

4. **清楚告訴使用者何時掛單**
   - 爆發前可小倉掛單：提前區只用預定倉位 40%。
   - 突破回踩可掛單：15m 已收線突破且即時價回到回測區。
   - 等待回踩：突破後現價偏高，只掛回測區限價單。
   - 已超追價上限：不追價，沒有回踩就放棄。

## 固定持倉規則

- TP1：平 25%，保護停損移到成本。
- TP2：平 30%，保護停損移到 +1R。
- TP3：平 30%，剩餘 15% 啟動 15m 趨勢追蹤。
- 原始 SL 與 TP 價位在按下「已下單」時鎖定。
- 保護停損只依上述規則向上移動，永不向下放寬。
- 同一根已收 1m K 同時碰到 SL 與 TP 時，預設保守視為先碰 SL。

## GitHub → Zeabur

1. 將 ZIP 內 6 個檔案放在 GitHub repository 根目錄。
2. Zeabur 建立服務並選擇該 GitHub repository。
3. Zeabur 會使用 `Dockerfile` 建置。
4. 將 `.env.example` 的內容貼入 Environment Variables。
5. 建立持久磁碟並掛載到 `/data`。
6. 對外連接埠使用 `PORT=8080`。

## 使用方式

- 先在網站上方輸入目前帳戶餘額並儲存。
- 「爆發前候選」會為每個訊號顯示 2% 風險建議名目、數量與最大虧損。
- 實際成交後按「已下單」，輸入成交價；系統會依實際價重新計算並自動填入名目金額。
- 系統以 1 倍名目計算損益。
- 提前離場時按「已平倉」，可輸入實際平倉價；留空使用最新即時價。
- 所有交易可匯出 CSV。

## 注意

每個訊號的 2% 是「單筆獨立風險」。若同時開多筆，總風險會相加，例如同時持有 3 筆且都尚未移動停損，理論總風險可能接近帳戶 6%。此工具不保證獲利，也不會自動連接 Gate 帳戶下單。小型幣可能有滑點、插針、流動性突然消失與價格操縱風險。
