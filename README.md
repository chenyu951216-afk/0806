# Gate 10X 早期爆發雷達 v4

這套系統把目標改成：盡量提早辨識類似 LAB／RAVE 的低基期、小市值、現貨吸籌、波動壓縮後主升段候選。任何「10X」標記都只是型態與非對稱潛力分級，不代表報酬保證。

## 三層訊號

1. **⭐10X 早期佈局**：尚未正式突破，但小市值非對稱、連續現貨吸籌、CVD、訂單簿持續性、BTC環境及早期歷史重播都通過。只在固定早期區掛單，預設只使用完整風險名目的 35%。
2. **突破確認**：已收 15m 突破，且後續已收 15m 回踩守住。只在固定回踩區限價，不追突破棒。
3. **潛力觀察**：10X輪廓尚未完整，不可視為系統下單訊號。

## 10X 潛力模型

- 市值與 FDV／流通比例（資料存在時）
- 上市歷史長度、距 90 日高點、7 日與 24 小時是否尚未過熱
- 15m 基底高度、波動壓縮、較高低點
- 12 根已收 K 的現貨量累積、一致性、上漲成交額比例
- 放量但價格受控的供給吸收特徵
- 現貨量是否領先合約量
- Gate WebSocket 主動買入比例、現貨 CVD
- 訂單簿買方優勢持續率、價差、買牆消失率
- OI／市值、OI增速、資金費率、多空擁擠
- BTC 市場狀態與全市場廣度
- 只用已收 15m／1h／4h／1d K 計算策略條件

## 深結構停損與最大虧損 5%

停損不再為了湊帳戶風險而硬塞得很近。固定 SL 會放在：

- 基底低點下方
- 最近 48 根結構低點下方
- 至少約 2.2 ATR 的正常噪音空間

網站可輸入每筆最大帳戶虧損 `0.1%～5%`。名目金額由以下關係反推：

`名目金額 = 帳戶餘額 × 風險% ÷ 進場到SL距離%`

若 1 倍名目不足以達到設定風險，系統會以 1 倍總名目上限封頂，因此實際虧損會低於設定值。早期首倉又會再乘以 `TEN_X_EARLY_TRANCHE_PCT`，預設只承擔完整單筆風險的 35%。

## 10X 持倉計畫

- TP1：預設平 15%，保護 SL 移到成本
- TP2：再平 20%，保護 SL 移到 +1R
- TP3：再平 20%
- 剩餘 45%：使用 1h EMA20／3ATR 寬尾隨，保留 3x、5x、10x 的可能性

3x／5x／10x 是 runner 里程碑，不是預測。系統不會在到達里程碑前假設一定能實現。

## 安全鎖

正式系統單仍受以下後端限制：

- 模擬交易樣本、Profit Factor、期望值與最大回撤門檻
- 單筆風險上限（網站可調，最高5%）
- 所有未保本持倉總風險上限
- 1倍總名目上限
- 高相關持倉限制
- 成交價必須在固定早期區或固定回踩區
- 固定 Plan 的 SL／TP／進場區建立後不因重掃而改動
