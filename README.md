# Gate 10X 雙池驗證雷達 v4.2

系統目標是盡量提早辨識低基期、小市值、現貨吸籌、波動壓縮後可能進入主升段的候選。任何 10X 分數或 3x／5x／10x 里程碑都不是報酬保證。

## v4.2：正式驗證池與探索樣本池

### FORMAL 正式驗證池

只有完整通過策略門檻的 EARLY／RETEST 訊號會進入 FORMAL 池。只有這個池內真正成交並封閉的交易能計入 20 筆、模式最低樣本、PF、期望值與最大回撤，並解鎖「我可以下的單」。

### EXPLORE 探索樣本池

探索池只收接近正式門檻的近失敗訊號，例如分數稍低、微結構樣本不足、CVD 尚未轉正或歷史重播樣本不足。它使用和正式池完全相同的固定限價、SL、TP、Runner 與真實成交追蹤，但：

- 不出現在「我可以下的單」；
- 不計入正式 20 筆；
- 不解鎖真人下單；
- 不改變正式池 PF 或期望值；
- 只用來比較不同分數帶與缺失條件的後續表現。

探索頁會顯示 `<78`、`78–81.9`、`82+` 分組的 PF／筆數，以及 2R 以上結果、曾達 5R MFE 的樣本和最常缺少的正式條件。

## 真實模擬訂單生命週期

所有新模擬限價都必須從 `WAITING_FILL` 開始，即使掃描當下即時價剛好在進場區，也不會直接假設成交。

1. `WAITING_FILL`：固定限價已建立，尚未成交。
2. `OPEN`：建立後的已收 1m K 真正碰到限價才成交。
3. `CLOSED`：碰固定 SL、保護 SL、Runner 尾隨或持有期限後結束。
4. `EXPIRED/CANCELLED/INVALIDATED`：未成交、到期或資料不完整，不算封閉績效。

同一根 K 同時碰進場與 SL 時採保守處理；跳空穿越 SL 也不假設能以更好的固定價格成交。Zeabur 重啟後會補抓已收 1m K，無法完整重建時標記 `INVALIDATED`。

## 正式驗證解鎖

預設要求：

- FORMAL 總封閉交易至少 20 筆；
- EARLY 或 RETEST 各自至少 8 筆，該模式才可能解鎖；
- Profit Factor 至少 1.20；
- 平均期望值至少 0.10R；
- 最大回撤不高於 8R。

探索池完全不參與以上計算。

## 風控與持倉管理

- 單筆帳戶風險可設定 0.1%～5%；
- 深結構 SL 依基底、結構低點、ATR 和緩衝計算；
- EARLY 首倉預設只使用完整風險名目的 35%；
- TP1 平 15% 並移至成本；
- TP2 再平 20% 並移至 +1R；
- TP3 再平 20%；
- 剩餘 45% 使用 1h 寬尾隨；
- 未保本總風險預設上限 8%；
- 真人總名目預設不超過帳戶餘額 100%；
- 高相關與同幣種重複持倉由後端拒絕。
